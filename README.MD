#Español
Este repositorio toma dos archivos de excel en una subcarpeta de Listas/, los cuales son excels que contienen la informacion cruda que entrega Autodedsk Inventor sobre los ensamblajes y partes, Les realiza un prepocesado y crea un formato en el que organiza en tablas los diferentes ensamblajes en una sola hoja de excel, mientras que la segunda digita todas las partes necesarias.
